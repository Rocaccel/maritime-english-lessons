# AGENTS.md — Maritime English Lessons

Уроки морского английского для судоводителей.
Сайт собирается из папки `docs/` через MkDocs.
Публикация идёт из ветки `gh-pages` на GitHub Pages.

## Структура

- `docs/` — источник сайта. Здесь правят уроки.
- `Unit-1/`, `Unit-2/` — копии из `docs/` для удобства. В сборке сайта не участвуют.
- `mkdocs.yml` — конфиг MkDocs. Секция `nav` задаёт меню сайта.
- `overrides/` — правки темы readthedocs: футер, кнопки, версии.
- `deploy.cmd` — деплой одним кликом.
- `site/` — собранная статика. В git не идёт.
- `README.md` — описание репозитория для людей.

## Как обновить урок

1. Отредактировать md-файл в `docs/Unit-N/`.
2. Картинку положить в ту же папку, что и md-файл.
3. Страницу с картинкой оформить как `imageN.md` и добавить её в `nav` в `mkdocs.yml`.
4. Скопировать изменённые файлы в корневой `Unit-N/`.
5. Проверить локально: `mkdocs serve`.
6. Запустить `deploy.cmd`.
7. Закоммитить изменения в `master`.

## Правила контента

- Первая строка `# ...` задаёт заголовок страницы.
- Заголовок вида `# Part 1` не нужен. Тема уже показывает имя страницы из `nav`.
- Подпись к картинке обязательна: `![русское описание](unit-1_part-1.png)`.
- Ссылки на картинки относительные, без папок.
- Каждая страница из `docs/` должна попасть в `nav`. Иначе её нет в меню.
- Термины даём по схеме: английское слово, русский перевод, короткое пояснение.
- Сайт русский. Заголовки и термины — английские.

## Деплой

- `deploy.cmd` выполняет `mkdocs gh-deploy` и пушит ветку `gh-pages`.
- Источник GitHub Pages: ветка `gh-pages`, папка `/`. Настроено один раз.
- GitHub собирает сайт 1–2 минуты после заливки.
- Если правки не видны, сборку запускают вручную:
  `gh api -X POST /repos/Rocaccel/maritime-english-lessons/pages/builds`
- Живой сайт: https://rocaccel.github.io/maritime-english-lessons/

## mkdocs

- mkdocs 1.6.1 стоит в портативном Python из `~/tools/tools.json`.
- `deploy.cmd` находит mkdocs сам: сначала в PATH, потом в `tools.json`.
- Сборка: `mkdocs build`. Локальное превью: `mkdocs serve`.
- `mkdocs serve` открывает сайт под путём `/maritime-english-lessons/`. Так задаёт `site_url`.
- Русский поиск требует mkdocs не старше 1.6.

## Git

- После каждого изменения: `git add <файл>; git commit -m "<тип>: <сообщение>"`.
- Типы: `feat`, `fix`, `docs`, `chore`.
- Push в remote — только по явной команде пользователя.
- Названий скиллов и инструментов в сообщениях коммитов не пишем.

## Скилл для разбора уроков

- `maritime-english-visualizer` — глобальный скилл. В репозитории его нет.
- Он выделяет термины, даёт перевод, объясняет грамматику и готовит описание для иллюстрации.
- Готовую иллюстрацию сохраняем как png в `docs/Unit-N/` и подключаем страницей `imageN.md`.

## Ограничения

- `site/` руками не правят и не коммитят.
- Тему и стили не меняют без согласования с пользователем.
- Корневые `Unit-1/`, `Unit-2/` не источник правды. Правки идут в `docs/`.
- После правок в `docs/` копии в корне синхронизируют.
