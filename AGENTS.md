# Agents Guide for Maritime English Lessons

Этот репозиторий содержит уроки по морскому английскому для русскоязычных курсантов и моряков.

## Основные правила работы

1. Входные данные урока — скриншоты с текстом.
   - Скриншоты кладутся в папку `lesson-N/`
   - Распознай текст со скриншотов с помощью OCR
   - Объедини распознанный текст в файл `lesson-N/lesson-N-text.md`
   - Сохраняй исходные скриншоты в папке урока для справки

2. Используй скилл `maritime-english-visualizer` для анализа любого учебного текста.
   Скилл находится в `skill/maritime-english-visualizer/SKILL.md`.

3. При обработке урока:
   - Определи область: навигация/лоция, устройство судна, маневрирование, радиосвязь SMCP, безопасность/аварии, метеорология, грузовые операции, право MARPOL/SOLAS.
   - Выдели ключевые термины и для каждого дай: перевод RU, определение EN, пример употребления, транскрипцию.
   - Объясняй типичную грамматику морского английского: must/should, пассивный залог в инструкциях.
   - Приводи стандартные фразы SMCP при необходимости.

4. Визуализация:
   - Формируй детальный промт на английском для генерации изображения.
   - Команда генерации: `python %USERPROFILE%\Desktop\GitHub\temp\generate_image.py "your detailed English prompt here"`
   - В ответе сообщай, что иллюстрация сгенерирована Imagine 4 и сохранена, дай подпись RU.

5. Ограничения:
   - Только профессиональная морская лексика, без бытовых упрощений.
   - Изображения должны соответствовать реальным судовым условиям и правилам IMO/МППСС.
   - Не давать рекомендаций, противоречащих безопасности мореплавания.
   - Подписи дублировать EN + RU.
   - Не выдумывать детали судов/портов/маршрутов, которых нет в исходном материале.

6. Структура уроков:
   - Каждый урок в отдельной папке `lesson-N/`
   - Храни исходные скриншоты, файл `lesson-N-text.md` с распознанным текстом, глоссарий, объяснения, промты и ссылки на изображения.

7. Язык общения с пользователем: русский по умолчанию, термины и примеры — английский.

Следуй инструкциям из `skill/maritime-english-visualizer/SKILL.md` как основному источнику.
